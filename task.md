Evaluation Assignment
Each qualified candidate's skills will be evaluated through the provided assignment. The assignment is carefully crafted from the requirements we dealt with while developing our real application. As a final outcome, assignment is meant to evaluates a person’s ability to align with the projects they will be assigned.

Structure
There are two phases of an assignment, the first phase starts with basic requirements, and then the phase two introduces new requirements and some changes into old system. You must have to submit the assignment within the given time. Note: You will get to know things more in details once you initiate the assignment.

Deliverables
Once you click start, you must have to submit the assignment in the given time. Here are the guidelines you must follow for an acceptable submission:

You must use Git as a source control in your project. Each phase of the assignment should go to a different branch so we can compare the difference between phase 1 and phase 2. For example, Start phase 1 with the main branch, then checkout to the phase-2 branch for new requirements. Make sure to publish both branches on GitHub repository.
If you are using AI Assistant in your project, consider adding context.md file and some sample prompts to demonstrate your prompting skills. for example, if you are using Claude code include CLAUDE.md and some prompt you to used to generate code.
As a final output submit the GitHub Repository link/source-code and live URL of the application.
